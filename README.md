## ⚙️ Menjalankan Proyek Secara Lokal
Jika Anda ingin menjalankan portfolio ini di komputer lokal Anda:

1.  Pastikan Anda telah menginstal Node.js.
2.  Clone repositori ini (atau unduh *source code*-nya).
3.  Buka terminal di direktori proyek dan jalankan perintah:
    ```bash
    npm install
    ```
4.  Setelah instalasi selesai, jalankan *development server*:
    ```bash
    npm run dev
    ```
5.  Buka browser Anda dan kunjungi URL yang muncul di terminal (biasanya `http://localhost:5174/`).
